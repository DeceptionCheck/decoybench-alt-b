# Third-party notices

DecoyBench v1 has no third-party runtime or vendored dependencies.
The implementation uses only the Python standard library
(`argparse`, `concurrent.futures`, `datetime`, `hashlib`,
`http.cookiejar`, `json`, `os`, `socket`, `sys`, `threading`,
`time`, `urllib`). Tests use only `unittest` plus the standard
library. No model weights, prompts, fonts, logos, or brand assets
are included.
